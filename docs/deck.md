# Recall: Six-Slide Demo Deck

## 1. Visual Memory Cannot Live In The Cloud

Homes, hospital wards, labs, and workshops need to find objects and understand
custody. They cannot continuously upload private video. Recall makes visual
memory possible by keeping every frame and model on a sub-10-watt edge device.

## 2. One Chip, Seven Jobs

- YOLO26 segmentation: object inventory and masks.
- YOLO26 pose: wrists and attribution.
- Stable tracking: identity through time.
- Qwen3-VL: one-time names, answers, and summaries.
- Whisper: spoken questions.
- Piper: spoken answers.
- SQLite: compact, inspectable memory.

## 3. Live Demo

1. Ask what is on the table.
2. Move the mug and ask where it went.
3. Let a person take the laptop and ask who took it.
4. Pull Ethernet and repeat.
5. Ask for the last ten minutes.

Keep the Insight masks and skeleton visible beside Recall's inventory, answer,
timeline, and evidence snapshots.

## 4. Why The Evidence Matters

Recall does not answer from a free-form video caption. It cites persistent
object IDs, typed events, timestamps, custody attribution, direction, and stored
frames. The VLM receives compact local evidence and cannot invent facts outside
that evidence.

## 5. Business Value

- Homes: find keys, glasses, medication, and packages.
- Hospitals: locate mobile equipment and review custody.
- Labs/workshops: find tools and understand handoffs.
- Retail back rooms: locate stock without exposing store video.

The same privacy property that constrains cloud AI is Recall's deployment moat.

## 6. Roadmap

- Multi-camera memory through the Modalix PCIe card.
- Depth for metric spatial language and shelf/bin location.
- Open-vocabulary segmentation for domain-specific inventory.
- Policy-controlled retention and role-based evidence access.
- Fleet-local analytics without centralizing raw video.
